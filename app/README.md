# Creatofolio app

The Next.js application. Setup, environment variables and database steps are
in the [repository README](../README.md); how it is built is in
[docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).

```bash
npm install     # also builds the Klecks drawing studio into public/klecks/
npm run dev     # http://localhost:3000
npm run lint
npx tsc --noEmit
npm run build
```
