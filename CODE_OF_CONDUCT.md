# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, keep feedback about the work and not the
person, and no harassment of any kind. This applies to issues, pull requests,
discussions and any other project space.

## Reporting

If someone's behaviour here makes the project unwelcoming, report it privately
to the maintainers through the repository's
**Security → Report a vulnerability** form (it reaches only the maintainers;
say that it is a conduct report). Reports are kept confidential.

Maintainers may remove comments, close threads or block accounts that break
these rules.
